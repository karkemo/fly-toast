# fly-toast 🍞

> A lightweight, customizable, and responsive toast notification library for web applications with zero dependencies.

---

## ✨ Features

- 🚀 **Zero Dependencies**: Lightweight and fast.
- 📱 **Fully Responsive**: Looks great on mobile, tablet, and desktop.
- 🎨 **Customizable**: Control positions, durations, colors, and themes.
- ⚡ **Modern JS**: Built using ES Modules (`import/export`).

---

## 📦 Installation

Install via **npm**:

```bash
npm install fly-toast
